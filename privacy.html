Site information

Privacy and accessibility

A lightweight static website with no advertising, analytics, sign-in, cookies or local storage operated by SIDM. Public collaboration is provided by GitHub.

Privacy

This starter website does not deploy an analytics service, marketing cookies, contact forms or a SIDM-managed visitor database. GitHub Pages hosts the site and may process technical information including IP addresses as part of providing the service. For details, consult GitHub's privacy information.

On the Projects page, the browser makes a request to GitHub's public API to retrieve community proposals. GitHub may receive technical information associated with that request. You can instead read those proposals directly in the community repository.

If you follow an external link, the destination site applies its own privacy and cookie practices. Posting on GitHub requires a GitHub account, and public issues and comments may be indexed by search engines.

Accessibility

We aim for clear structure, keyboard navigation, legible text and a responsive presentation. Search and subject filters are optional enhancements; the site remains readable without them. We have not commissioned an independent accessibility audit of this first edition.

If you find an accessibility barrier or an error, report it through GitHub. The website can be updated without relying on a proprietary publishing platform.

Last reviewed

Initial website edition: 4 November 2026. Policies should be reviewed before adding any embedded media, external analytics, membership forms or mailing-list integrations.
